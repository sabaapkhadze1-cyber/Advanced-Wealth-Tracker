 K კოეფიციენტის გამოთვლის ფორმულა



`K = (სახელის ასოების რაოდენობა + გვარის ასოების რაოდენობა) / დაბადების რიცხვი`

**ჩემი მონაცემები:**
* **სახელი:** Saba (4 ასო)
* **გვარი:** Apkhadze (8 ასო)
* **დაბადების რიცხვი:** 10
* **გამოთვლა:** (4 + 8) / 10 = **1.2**

**შედეგი:** პროექტში **K = 1.2**.  
საბოლოო დანაზოგი ითვლება ფორმულით: `Final Savings = (Income - Expenses) * 1.2`
